## 1. Identity and stack

- **Product:** Fize — restaurant operations app for Colombia: menu by QR, orders straight to the kitchen screen,
  recipes with per-portion cost, inventory that decrements on sale, sales history, WhatsApp ordering.
- **Two run modes in one tree:**
  - **Local** (`/local/*`) — runs entirely in the browser (IndexedDB, no account). Can publish a signed menu snapshot
    to the edge so diners order by WhatsApp.
  - **Cloud** (`/dashboard/*`, `/api/*`) — Astro SSR on a Cloudflare Worker with D1 + R2 + KV and its own sessions.
- **License:** AGPL-3.0-only. **Workspace:** pnpm monorepo; `src-astro` is the only app package (`cores/gos-client` is
  a local file dependency, `@swal/ui` and `@swal/vault` come from npm). No Next.js, no Prisma in the shipped tree.

| Layer | Verified in tree |
|---|---|
| Frontend | Astro 7.3 + Svelte 5 (runes) + TypeScript 5.9, Tailwind **not** used (see §5.5) |
| UI | `@swal/ui` + hand-written CSS on `--swal-*` tokens, light/dark |
| Backend | Cloudflare Worker (`@astrojs/cloudflare` 14), D1 + R2 + KV, 32 REST route files / 62 handlers |
| Offline | `vite-plugin-pwa` + Workbox, `idb`, own offline queue, 125 precached entries |
| AI | Cloudflare Workers AI for Fi'ze recommendations, local fallback; **no** Ollama/LLM in this tree |
| Tests | Vitest 5 (1118 tests) + Playwright 1.64 (38 specs) + axe-core for WCAG |

## 6. Repo hygiene decision (this change)

`.gitcore/skill-registry.json` and `docs/SWAL/` appeared as untracked on every run of `git status` on this machine.
Both are **generated**, not authored:

- `.gitcore/skill-registry.json` is written by `~/.hermes/scripts/skill-registry-refresh.sh` as a GitCore-readable copy
  of `.atl/skill-registry.md`; it carries absolute paths and changes on every refresh (`.atl/` was already ignored for
  the same reason).
- `docs/SWAL/NEW_SCOPES_2026-09_SDD_HIBRIDO.md` is written by `swal-docs-propagate.sh` from an internal template + SRS.

Decision: **ignore both in `.gitignore`, do not delete them.** They stay on disk and remain usable locally; ignoring
them keeps the working tree honest, so a real untracked file is visible instead of buried under refresh churn.
Versioning them would commit machine-specific paths and a regenerated document that nobody consumes outside this node.

Working-tree note: at the time of writing, `git status` also lists changes that are **not** part of this review —
`README.md` (stack line), `src-astro/package.json` + `pnpm-lock.yaml` (Tailwind removal), `src-astro/e2e/a11y.spec.ts`
(a11y scope widened to 6 routes) and `docs/WCAG-AUDIT-REPORT.md` (rewritten for that scope). This review only touches
`.gitignore` and adds this file.
